# Bike Sharing Demand Prediction

## Project Title
Bike Sharing Demand Prediction Using Machine Learning

## Objective
The objective of this project is to predict the total number of bikes rented using time, seasonal, weather and environmental features. The project includes data preparation, exploratory data analysis, model building, evaluation and model selection.

## Dataset Used
**Dataset:** UCI Bike Sharing Dataset (hourly data)

**Source:** UCI Machine Learning Repository

**Original source:** https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

The dataset contains hourly and daily bike rental counts from 2011 and 2012 with corresponding weather and seasonal information.

## Models Used
1. **Linear Regression** — used as a simple baseline regression model.
2. **Random Forest Regressor** — used to capture nonlinear relationships and interactions between features.
3. **Gradient Boosting Regressor** — used as an ensemble regression approach that can model complex patterns.

The notebook compares the models using MAE, RMSE and R2 score.

## Important Note
The `casual` and `registered` columns are excluded from model predictors because they are components of the target `cnt` (total rental count). This prevents target leakage.

## How to Run
1. Open the notebook in Google Colab.
2. Run all cells from top to bottom.
3. The notebook downloads the dataset through the UCI dataset interface.
4. It creates the CSV and saved model automatically.
5. Upload the notebook, CSV, model file and README to the GitHub repository.
